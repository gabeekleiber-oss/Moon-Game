## DECISIONS MADE
- Presets are flat dicts keyed by Environment property names (apply = env.set), so easing/quality/Unreality are pure and testable headless.
- Enum/bool keys switch at t>=0.5 when easing; do enum changes under a fade (Acts.transition_to already fades).
- No-strobe rule is enforced in code: TV changes level <=2.5x/s with easing; LightFlicker.max_changes_per_second is the test detector (flags a real 12 Hz strobe).
- Default shadow casters in the helpers: window + moon only (=2, the ART_BIBLE 4 limit); lamp/candle/TV are unshadowed.
- Fixed scripts/tools/shot.sh: it now runs `--import` first. Without it, a newly added `class_name` is unknown to the shot scene (parse error, and Godot then spins at 100% CPU forever).
- LightShaft = FogVolume ellipsoid only thickens a shaft; the shaft itself is a shadowed spot/directional light with light_volumetric_fog_energy > 0 in an Environment with volumetric fog (all looks). Unverified in a real window.
- Quality ladder: high/medium/low (auto=high); low drops volumetric fog + SSAO.
