## DECISIONS MADE
- Presets are flat dicts keyed by Environment property names (apply = env.set), so easing/quality/Unreality are pure and testable headless.
- Enum/bool keys switch at t>=0.5 when easing; do enum changes under a fade (Acts.transition_to already fades).

- Default shadow casters in the helpers: window + moon only (=2, the ART_BIBLE 4 limit); lamp/candle/TV are unshadowed.
- Quality ladder: high/medium/low (auto=high); low drops volumetric fog + SSAO.
