## DECISIONS MADE
- Ducking/muffling use AudioEffectAmplify + LowPass on Music and Amb (independent of the user volume setting). Dialogue ducks -8 dB; pause muffles to 900 Hz.
- Headless timers run faster than wall-clock: the flea rate limiter (Time.get_ticks_msec) must be reset in tests via Audio._last_ms.clear().
- Speaker ids are matched by keyword (elsa, mary, frank, sweaty, clement, edith, gronfiser/primo, errante, moon, crumpis, crumpalump, curt, christopher/self/you); unknown ids get a stable derived voice. Real story ids may differ: add keys to VoiceProfiles.PROFILES.
- Reverb is an AudioEffectReverb on each of SFX/Amb/Voice (buses can't send to two places); Audio.set_reverb(preset) changes all three. Master volume stays owned by GameSettings.
- Sounds are generated as AudioStreamWAV buffers (Synth), not AudioStreamGenerator: deterministic, cacheable, testable headless. Procedural SFX is the doc default (audio decision still pending the human).
